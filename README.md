# Glow Care - Premium Beauty & Perfume E-commerce Platform

## 🌟 Overview
Glow Care is a full-stack e-commerce platform specializing in skincare, beauty products, and perfumes with integrated dropshipping and manual bank transfer payments in Nigerian Naira (NGN).

## 📋 Features
- ✅ 1000+ Products (Skincare, Beauty, Perfumes)
- ✅ Advanced Shopping Cart & Checkout
- ✅ Manual Bank Transfer Payments (Opay Integration)
- ✅ Dropshipping Integration (AliExpress, Oberlo, Printful)
- ✅ Admin Dashboard
- ✅ User Authentication
- ✅ Order Management
- ✅ Responsive Design
- ✅ SEO Optimized
- ✅ Mobile First Approach

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Payment**: Manual Bank Transfer (Opay)
- **Dropshipping**: AliExpress API, Oberlo, Printful
- **Hosting**: Vercel/Heroku/Railway

## 🚀 Getting Started
1. Clone repository: `git clone https://github.com/davidpaulineous-blip/glow-care.git`
2. Install dependencies: `npm install`
3. Configure .env file (copy from .env.example)
4. Start server: `npm start`
5. Visit http://localhost:3000
